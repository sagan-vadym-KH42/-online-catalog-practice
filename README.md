## Тема проєкту

Онлайн-каталог товарів (мінімальний e-commerce).

Проєкт реалізований послідовно у трьох частинах навчальної практики.

## Частина 1

Початковий програмний прототип онлайн-каталогу.

Основні можливості:
- перегляд товарів;
- категорії;
- пошук;
- кошик;
- оформлення замовлень;
- збереження даних;
- тестування основних функцій.

Технології: Python, JSON, Git.

## Частина 2

Серверна частина онлайн-каталогу.

Основні можливості:
- REST API;
- CRUD для товарів, категорій та замовлень;
- база даних;
- ORM;
- middleware;
- валідація;
- Swagger / OpenAPI;
- тестування API.

Технології: Node.js, Express.js, Sequelize, SQLite, Swagger.

## Частина 3

Клієнтська частина онлайн-каталогу.

Основні можливості:
- каталог товарів;
- пошук і фільтрація;
- кошик;
- оформлення замовлення;
- маршрутизація;
- взаємодія з REST API;
- адаптивний інтерфейс;
- localStorage.

Технології: React, JavaScript, SCSS, REST API.
